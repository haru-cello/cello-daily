Cello Daily alpha
Cost to run this version: 0 JPY if hosted on a free static host.

Important: microphone recording requires HTTPS (or localhost). Opening index.html directly may not permit recording.

Test locally:
1. Open a terminal in this folder.
2. Run: python -m http.server 8000
3. Visit http://localhost:8000

For phone/PWA testing, deploy this folder to an HTTPS static host such as GitHub Pages, Cloudflare Pages, or Vercel.
All practice data and recordings stay in the browser's local storage in this alpha version. Clearing browser/site data can erase them.
